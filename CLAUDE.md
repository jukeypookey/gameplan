# gameplan

Single-page app: `gameplan.html`, published via GitHub Pages at
https://jukeypookey.github.io/gameplan/gameplan.html from the `main` branch of
https://github.com/jukeypookey/gameplan.git.

## Workflow

After making any changes the user asks for, commit and push to GitHub
automatically (no need to ask first) so the GitHub Pages site stays current.
Use short, descriptive commit messages. Git PATH note (Windows): if `git` is
not found, prepend `$env:Path += ";C:\Program Files\Git\cmd"` to the command.
